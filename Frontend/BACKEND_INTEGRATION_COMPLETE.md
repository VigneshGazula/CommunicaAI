## User Flow (Production)

```
1. Setup Interview
   └─> POST /api/interviews
   └─> Questions auto-generated by backend

2. Live Interview
   ├─> Load questions from backend
   ├─> Display question
   ├─> TTS speaks question (browser)
   ├─> User records audio
   ├─> Submit audio to backend
   │   └─> Backend:
   │       ├─> Upload to Cloudinary
   │       ├─> Transcribe with Gemini AI
   │       └─> Evaluate with Gemini AI
   ├─> Receive transcript + scores
   ├─> Display transcript
   ├─> Store evaluation
   └─> Next question

3. Complete Interview
   └─> POST /api/interviews/{id}/complete
   └─> Backend generates results

4. View Results
   └─> GET /api/interviews/{id}
   └─> Display transcript + evaluations
```

## What Changed

### Before (Mock)
- Questions: Hardcoded in frontend
- Transcription: Mock service returning random text
- Evaluation: Mock calculation based on text length
- Storage: localStorage
- Persistence: Lost on browser clear

### After (Production)
- Questions: Generated by backend from database
- Transcription: Gemini AI (real speech-to-text)
- Evaluation: Gemini AI (real answer analysis)
- Storage: PostgreSQL database
- Persistence: Permanent, cross-device
